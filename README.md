# Agent-team set-up and literature-reference errors: pre-registration

This repository is the pre-registration record for a study of how the set-up of an AI agent team affects invented or misreported literature references. The team has a Lead, a Doer and an Auditor, and it works from memory without tools. The study's code name is B1.

Authors are withheld during peer review.

## Files

| File | What it holds |
| --- | --- |
| [PREREGISTRATION.md](PREREGISTRATION.md) | The frozen design: the treatments, sample, hypotheses and verdict rules, dependent variables, manipulation check, pilot gates, exclusion and stopping rules, analysis plan and run-to-run tolerance |
| [docs/dv_specification.md](docs/dv_specification.md) | The formula for every dependent variable, citation label and reported share |
| [AMENDMENTS.md](AMENDMENTS.md) | Every dated change made after the first registration tag |

The prompt file, config, verifier version and analysis code are added as the registration tags below require. A hash file (SHA-256) of every frozen file is added at the second tag.

## Registration tags

| Tag | When | What it fixes |
| --- | --- | --- |
| `prereg-tag1` | Before the first paid pilot call | Hypotheses, contrasts, deciding DVs, verdict rules, DV rules, exclusion, stopping and gate rules, the ceiling and tolerance formulas, prompts and config |
| `prereg-tag2` | Before the main run | Values set from the pilot (manipulation-check ceilings, the author-rule decision, tolerance numbers), main-run spending caps, the analysis code and the hash file |

Any change after `prereg-tag1` is recorded in [AMENDMENTS.md](AMENDMENTS.md) with its date, the reason, and which data, if any, existed when it was made.
